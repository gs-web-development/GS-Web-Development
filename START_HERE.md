# 🌐 ORBITAL CONNECT - WEB DEVELOPMENT
## Global Solution FIAP

Bem-vindo ao projeto Orbital Connect! Este é um projeto web interativo desenvolvido com HTML5, CSS3 e JavaScript puro para a disciplina de Web Development da FIAP.

### 🚀 INÍCIO RÁPIDO

1. **Abra `index.html` em seu navegador**
   ```bash
   # Ou use um servidor local
   python -m http.server 8000
   # Depois acesse http://localhost:8000
   ```

2. **Explore as funcionalidades:**
   - 📸 Slideshow com 3 imagens
   - 📝 Formulário com validação
   - 🎯 Quiz com 10 perguntas
   - 🎨 3 temas de cores (escuro, claro, verde)

### 🚀 PRÓXIMOS PASSOS

1. **Configure o GitHub**
   - Crie uma organização
   - Crie um repositório
   - Faça push dos commits

2. **Preencha equipe.txt**
   - Adicione nomes dos integrantes
   - Adicione RMs
   - Adicione link do repositório

3. **Faça commits**
   - Mínimo 15 commits
   - Mensagens descritivas
   - Histórico completo

4. **Prepare a entrega**
   - Crie arquivo ZIP
   - Teste tudo localmente
   - Envie no Microsoft Teams
