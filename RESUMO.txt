🚀 COMEÇANDO AGORA
═══════════════════════════════════════════════════════════════════════════

1. VISUALIZAR O PROJETO
   ├─ Abra index.html em um navegador
   ├─ Ou use: python -m http.server 8000
   ├─ Depois acesse: http://localhost:8000

2. TESTE TODAS AS FUNCIONALIDADES
   ├─ Slideshow: Use setas e dots
   ├─ Formulário: Tente deixar campos em branco
   ├─ Quiz: Responda as 10 perguntas
   ├─ Temas: Clique no botão 🎨
   ├─ Responsividade: Redimensione o navegador

3. CONFIGURAR GITHUB
   ├─ Crie organização em: github.com/organizations/new
   ├─ Crie repositório: GS-Web-Development
   ├─ Adicione remote: git remote add origin [URL]
   ├─ Faça push: git push -u origin main

4. PREENCHER EQUIPE.TXT
   ├─ Abra equipe.txt
   ├─ Adicione nomes dos integrantes
   ├─ Adicione RMs
   ├─ Adicione link do repositório

5. FAZER COMMITS
   ├─ Cada funcionalidade = 1 commit
   ├─ Mínimo 15 commits
   ├─ Mensagens descritivas

6. ENTREGAR NO TEAMS
   ├─ Crie arquivo web_development.zip
   ├─ Envie no Microsoft Teams
   ├─ Apenas um integrante envia

📞 SUPORTE RÁPIDO
═══════════════════════════════════════════════════════════════════════════

Problema: Slideshow não funciona
Solução: Verifique se as imagens existem em images/

Problema: Formulário não valida
Solução: Abra console (F12) e veja mensagens de erro

Problema: Temas não trocam
Solução: Verifique localStorage do navegador (F12 > Application)

Problema: Quiz não calcula
Solução: Veja console para erros JavaScript

Problema: Links quebrados
Solução: Verifique paths das imagens e páginas
